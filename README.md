# Unreal Multiplayer Combat Portfolio

Unreal Engine과 C++를 기반으로 제작하는 멀티플레이 전투 시스템 포트폴리오 프로젝트입니다.

실무에서 경험한 캐릭터/전투 개발을 바탕으로, 멀티플레이 환경에서의 전투 구조와 네트워크 처리, Gameplay Ability System(GAS)을 직접 설계하고 구현하는 것을 목표로 합니다.

## Development Environment

- Unreal Engine
- C++
- Gameplay Ability System (GAS)

## Main Goals

- Server Authority 기반 전투 처리
- 공격 및 피격 시스템
- Hit Detection
- Damage 처리 및 Replication
- Gameplay Ability System 기반 Skill 구조
- GameplayEffect / GameplayTag 활용
- Cost / Cooldown 처리
- 캐릭터 상태 및 행동 제한
- 멀티플레이 환경에서의 동기화 처리

## Purpose

단순히 기능 구현 결과만 보여주는 것이 아니라,

- 어떤 문제를 해결하려 했는지
- 왜 해당 구조를 선택했는지
- 멀티플레이 환경에서 어떤 부분을 고려했는지
- 구현 과정에서 발생한 문제를 어떻게 해결했는지

를 코드와 함께 정리하는 것을 목표로 합니다.
